Next Decision Points

To enable the private model

Provision a self-hosted DeepSeek open-weight model behind a private API-compatible endpoint, then configure:

  • AI_MODE=private
  • AI_PRIVATE_ENDPOINT and AI_PRIVATE_MODEL
  • AI_PRIVATE_API_KEY, if required
  • AI_PRIVATE_ALLOWED_HOSTS in production

To enable hosted DeepSeek for a tenant (do not do this yet)

AI_MODE=hosted_limited and the adapter code exist (2026-09-14), but enabling real egress for any tenant requires the 13A privacy/contractual/egress review to pass first. Once it does, for that tenant only:

  • AI_MODE=hosted_limited, AI_HOSTED_MODEL
  • AI_HOSTED_API_KEY in production
  • An ORGANIZATION-scope FeatureFlagRule enabling phase13.hosted_ai_egress for that organization's ID specifically -- never flip the flag's global default_enabled

Release blockers

Do not claim Phase 13 complete until these are resolved:

  • Provision and verify the restricted production database runtime role
  • 13A's threat model, privacy review, and labelled evaluation set

  • A live integration proof of the ClamAV scan and tesseract OCR round trip, including PDF rasterization -- done 2026-09-14 against real bytes (images and PDFs); found and fixed a real production bug in the PDF path along the way
  • Adversarial coverage beyond document validation: cross-tenant citation probing done 2026-09-14; prompt injection and malicious OCR text still open
  • Fixture-based correctness tests for each 13E/13F adviser's own math/SQL -- done 2026-09-14, all thirteen services now covered against real posted data.
